# आर्म प्रोफाइल

सीधी, empty-gripper भुजाओं से संदर्भ सेटिंग्स। प्रत्येक निर्देशिका में एक नियंत्रक फ़ाइल और प्रति मोटर एक प्रोफ़ाइल होती है, जिसमें PID और दिशात्मक वेग फ़ीडफ़ॉरवर्ड शामिल है। दोनों नियंत्रक मोटरों के लिए गुरुत्वाकर्षण मॉडल का उपयोग करते हैं 2–4; मोटर्स 1, 5 और 6 शून्य गुरुत्वाकर्षण प्रयास प्राप्त करते हैं।

| प्रोफाइल | पुनः चलाने की गति | त्वरण | दायरा |
| --- | ---: | ---: | --- |
| [SO-101](../../../../../../host/arm-control/profiles/so101/controller.json) | 1,000 counts/s; प्रोफ़ाइल छत 1,500 | 10,000 counts/s² | ट्यूनिंग सेटिंग्स बरकरार रखीं। M1 गति दोलन और धीमी M2 यात्राएं अनसुलझी रहती हैं। |
| [SO-102](../../../../../../host/arm-control/profiles/so102/controller.json) | 2,000 counts/s | 15,000 counts/s² | वर्तमान fixed-profile तुलना सेटिंग्स। इस तेज़ कॉन्फ़िगरेशन को अभी भी हार्डवेयर सत्यापन की आवश्यकता है। |

ये शुरुआती बिंदु हैं, सार्वभौमिक डिफ़ॉल्ट या पूर्ण ट्यूनिंग का दावा नहीं। SO-102 प्रोफ़ाइल निश्चित M1 D=0.0625, M6 P=4 और एक 100 एमएस रैंप का उपयोग करती है। पुराने रीप्ले में चलते समय M1 D=0.75, M6 P=16 और एक 180 एमएस रैंप का उपयोग किया गया था, इसलिए यह फ़ाइल उस पुराने रन को पुन: पेश नहीं करती है।

<a id="use"></a>
## उपयोग करें

चुनी गई नियंत्रक फ़ाइल में `followerPort` सेट करें। सापेक्ष प्रोफ़ाइल और गुरुत्वाकर्षण पथ को अक्षुण्ण रखें। रिपॉजिटरी रूट से:

```sh
npm run replay -- host/arm-control/profiles/so102/controller.json POSES.json
npm run replay -- host/arm-control/profiles/so102/controller.json POSES.json --run
```

अन्य प्रोफ़ाइल के लिए `so101` का उपयोग करें। पहला आदेश पूर्वावलोकन; दूसरा हाथ हिलाता है और उसे अंतिम मुद्रा में रखते हुए छोड़ देता है। रीप्ले प्रोफाइल को RAM पर लागू करता है। टेलीऑपरेशन के लिए, `leaderPort` भी सेट करें और प्रत्येक जोड़ में `leaderId`, `mapping` और कोई भी direction/center ओवरराइड जोड़ें; [मैपिंग गाइड](../../../tools/teleoperation/README.md#mapping-and-control) देखें।

गुरुत्वाकर्षण मॉडल में फिटिंग के दौरान उपयोग किए जाने वाले एनकोडर अंशांकन शामिल हैं। प्रीफ़्लाइट के लिए आवश्यक है कि यह कनेक्टेड आर्म से मेल खाए। **इस जांच को पूरा करने के लिए किसी अन्य हाथ के एनकोडर ऑफसेट की नकल न करें।** अपने हाथ को कैलिब्रेट करें, उसके मॉडल को फिट करें या अनुकूलित करें, और full-speed उपयोग से पहले परिणाम को मामूली गति से मान्य करें। माउंटिंग, लिंक ज्यामिति या पेलोड में परिवर्तन के लिए भी सत्यापन की आवश्यकता होती है। [गुरुत्वाकर्षण मॉडल प्रारूप](../models/README.md) और [ट्यूनिंग प्रक्रिया](../../../tools/tuning/README.md)] देखें।

ये फ़ाइलें सार्वभौमिक भौतिक अंशांकन मुद्रा को परिभाषित नहीं करती हैं। नया अंशांकन बनाने से पहले [reference-pose गाइड](../../../tools/settings/README.md#choose-the-reference-pose) का पालन करें। सभी मोटरों को 2048 पर सेट करने से, उसकी सहेजी गई सीमाओं और ट्रैकिंग त्रुटि के अधीन, उस बांह पर कैप्चर की गई मुद्रा पुन: उत्पन्न हो जाती है; यह किसी भी बंडल मॉडल के शून्य पोज़ को स्वचालित रूप से पुन: उत्पन्न नहीं करता है।
