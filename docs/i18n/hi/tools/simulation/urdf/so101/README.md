# SO-101 अनुयायी मॉडल

URDF और 13 संदर्भित STL मेश को [रोबोट स्टूडियो के SO-ARM100 रिपॉजिटरी](https://github.com/TheRobotStudio/SO-ARM100/tree/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101), कमिट `a758567c3978dfeefe282ede0500085a48fe8f78` से अपरिवर्तित कॉपी किया गया।

स्रोत: रोबोट स्टूडियो, SO-101. अपस्ट्रीम के तहत वितरित [अपाचे 2.0 लाइसेंस](../../../../../../../tools/simulation/urdf/so101/LICENSE.txt)। `source.json` अपस्ट्रीम पथ और SHA-256 चेकसम सूचीबद्ध करता है। दर्शक `so101_new_calib.urdf` का उपयोग करता है; leader-specific भाग और पुराने अंशांकन संस्करण को बंडल नहीं किया गया है।

आयातक केवल अस्थायी पूर्वावलोकन फ़ाइलों में टकराव को हटाता है। यह दृश्य ज्यामिति, संयुक्त परिवर्तन और जड़त्वीय गुणों को संरक्षित करता है। एनकोडर मैपिंग और अंशांकन मान्यताओं के लिए [दर्शक गाइड](../../README.md) देखें।
