# उपकरण

STS सर्वो के साथ काम करने के लिए उपयोगिताएँ। प्रत्येक गाइड में सेटअप निर्देश, कमांड और हार्डवेयर आवश्यकताएँ शामिल हैं। एप्लिकेशन विकास के लिए, [Node.js सर्वो ड्राइवर](../host/servo-driver/README.md) का उपयोग करें, जो इस रिपॉजिटरी से निर्मित स्टैंडअलोन एनपीएम पैकेज के रूप में उपलब्ध है। रीप्ले और टेलीऑपरेशन [आर्म कंट्रोलर और ग्रेविटी मॉडल](../host/arm-control/README.md) साझा करते हैं।

एक नए तंत्र के लिए: [ऑफ़सेट और सीमा](settings/README.md#choose-the-reference-pose) को कैलिब्रेट करें, पोज़ रिकॉर्ड करें, फिर ट्यून करें और मुआवजे को मान्य करें। मौजूदा पोज़ और गुरुत्वाकर्षण मॉडल का पुन: उपयोग करते समय सत्यापित अंशांकन रखें।

| औज़ार | प्रयोजन |
| --- | --- |
| [स्वचालित ट्यूनिंग](tuning/README.md) | बार-बार चाल और लंबे समय तक सत्यापन होल्ड के साथ सेटिंग्स के सीमित बैचों की तुलना करें। |
| [टेलीमेट्री व्यूअर](simulation/README.md) | लाइव टेलीमेट्री देखें और बंडल किए गए SO-101 और SO-102 मॉडल के साथ रिकॉर्डिंग चलाएं; कोई बस पहुंच नहीं. |
| [टेलीऑपरेशन](teleoperation/README.md) | एक hand-operated नेता से एक अनुयायी को नियंत्रित करें। |
| [रिकॉर्डिंग और रीप्ले](poses/README.md) | नामित पोज़ रिकॉर्ड करें; लीगेसी या एक्सटेंशन सेटिंग्स के साथ दोबारा चलाएं, या रिकॉर्ड किया गया टेलीऑपरेशन सत्र चलाएं। |
| [खोज, अंशांकन और सेटिंग्स](settings/README.md) | मोटर ढूंढें, संयुक्त ऑफसेट और सीमाओं को कैलिब्रेट करें, और लगातार सेटिंग्स का बैकअप लें या पुनर्स्थापित करें। |
| [हार्डवेयर तुलना परीक्षण](hw-diff-tests/README.md) | एक समर्पित सर्वो बेंच पर फ़ैक्टरी और कस्टम फ़र्मवेयर व्यवहार की तुलना करें। |
| [बस बेंचमार्क और टेलीमेट्री](diagnostics/README.md) | संचार विलंबता को मापें और असामान्य मूल्यों के लिए स्थिर रीडिंग की जांच करें। |
| [फर्मवेयर फ्लैशिंग और रिकवरी](flash/README.md) | कस्टम या बंडल फ़ैक्टरी फ़र्मवेयर फ़्लैश करें, बाधित अपलोड पुनर्प्राप्त करें और फ़ैक्टरी सेटिंग्स की मरम्मत करें। |

Node.js टूल के लिए Node.js 20 या नए संस्करण की आवश्यकता होती है। फ़्लैशिंग और सेटिंग्स पुनर्प्राप्ति के लिए Python 3.10 या नए संस्करण की आवश्यकता होती है। सिमुलेशन पायथन 3.12 का उपयोग करता है। रिपॉजिटरी रूट से कमांड चलाएँ और हार्डवेयर कनेक्ट करने से पहले प्रासंगिक गाइड का पालन करें: तुलना परीक्षण मोटरों को स्थानांतरित कर सकते हैं और सेटिंग्स को ओवरराइट कर सकते हैं, और फ्लैशिंग सर्वो को नुकसान पहुंचा सकती है।

<a id="offline-checks"></a>
## ऑफ़लाइन जाँच

रिपॉजिटरी रूट से चलाएँ। पहले नोड निर्भरताएँ और प्रत्येक पायथन टूल की आवश्यकताएँ स्थापित करें। इनमें से कोई भी कमांड सीरियल पोर्ट नहीं खोलता या हार्डवेयर को स्थानांतरित नहीं करता।

| आदेश | कवरेज |
| --- | --- |
| `make verify` | फ़र्मवेयर बिल्ड, सी रिग्रेशन परीक्षण, register/storage अनुबंध और छवि लेआउट। [टूलचेन सेटअप](../firmware/README.md) देखें। |
| `npm test` | ड्राइवर, साझा नियंत्रक और सभी Node.js उपकरण। |
| `npm run test:driver-package` | कैश्ड एनपीएम निर्भरता का उपयोग करके ड्राइवर पैकेजिंग और पृथक इंस्टॉलेशन। |
| `make flash-verify PYTHON=tools/flash/.venv/bin/python` | सिम्युलेटेड सीरियल डिवाइस के साथ फ्लैशिंग और फ़ैक्टरी सेटिंग्स पुनर्प्राप्ति। |
| `PYTHONPATH=tools/simulation tools/simulation/.venv/bin/python -m unittest discover -s tools/simulation/test` | मॉडल, रिकॉर्डिंग पाठक और दर्शक व्यवहार। |

हार्डवेयर तुलना [समर्पित बेंच सुइट](hw-diff-tests/README.md); का उपयोग करती है; यह सेटिंग्स को बदल सकता है और टेम्पलेट रीसेट कर सकता है। इकट्ठे तंत्र पर संचार और स्थिर टेलीमेट्री के लिए [डायग्नोस्टिक्स](diagnostics/README.md) का उपयोग करें।
