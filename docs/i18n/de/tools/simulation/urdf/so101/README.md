# SO-101 Follower Modell

URDF und 13 referenzierten STL-Netze, die unverändert aus [dem SO-ARM100-Repository](https://github.com/TheRobotStudio/SO-ARM100/tree/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101) des Roboterstudios, `a758567c3978dfeefe282ede0500085a48fe8f78` übertragen wurden.

Quelle: The Robot Studio, SO-101. Verteilt unter der vorgelagerten [Apache 2.0 Lizenz](../../../../../../../tools/simulation/urdf/so101/LICENSE.txt). `source.json` Listen vorgelagerte Pfade und SHA-256 Prüfsummen. Der Betrachter verwendet `so101_new_calib.urdf`; leader-specific Teile und die ältere Kalibriervariante sind nicht gebündelt.

Der Importeur entfernt Kollisionen nur in temporären Vorschaudateien. Er bewahrt visuelle Geometrie, Gelenktransformationen und Trägheitseigenschaften. Siehe die [Viewer-Guide](../../README.md) für Encoder-Mapping und Kalibrierung Annahmen.
