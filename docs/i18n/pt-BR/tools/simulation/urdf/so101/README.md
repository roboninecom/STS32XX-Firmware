# SO-101 modelo seguidor

URDF e 13 referenciaram malhas STL copiadas inalteradas do [repositório SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100/tree/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101) do Robot Studio, commit `a758567c3978dfeefe282ede0500085a48fe8f78`.

Fonte: The Robot Studio, SO-101. Distribuído sob a licença upstream [Apache 2.0](../../../../../../../tools/simulation/urdf/so101/LICENSE.txt). `source.json` lista caminhos upstream e SHA-256 somas de verificação. O visualizador usa `so101_new_calib.urdf`; leader-specific as peças e a variante de calibração mais antiga não estão incluídas no pacote.

O importador remove colisões somente em arquivos de visualização temporários. Preserva a geometria visual, as transformações das juntas e as propriedades inerciais. Consulte o [guia do visualizador](../../README.md) para mapeamento do codificador e suposições de calibração.
