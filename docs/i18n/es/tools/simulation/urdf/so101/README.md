# SO-101 modelo seguidor

URDF y 13 hicieron referencia a las mallas STL copiadas sin cambios desde [el repositorio SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100/tree/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101) de The Robot Studio, confirme `a758567c3978dfeefe282ede0500085a48fe8f78`.

Fuente: The Robot Studio, SO-101. Distribuido bajo la [licencia Apache 2.0](../../../../../../../tools/simulation/urdf/so101/LICENSE.txt). `source.json` enumera rutas ascendentes y SHA-256 sumas de verificación. El espectador usa `so101_new_calib.urdf`; leader-specific las piezas y la variante de calibración anterior no están incluidas.

El importador elimina las colisiones sólo en archivos de vista previa temporales. Conserva la geometría visual, las transformaciones conjuntas y las propiedades inerciales. Consulte la [guía del visor](../../README.md) para conocer los supuestos de calibración y mapeo del codificador.
