# أدوات

أدوات مساعدة للعمل مع STS الماكينات. يتضمن كل دليل تعليمات الإعداد والأوامر ومتطلبات الأجهزة. لتطوير التطبيقات، استخدم [Node.js servo driver](../host/servo-driver/README.md)، المتوفر كحزمة npm مستقلة مبنية من هذا المستودع. إعادة التشغيل والتشغيل عن بعد يشاركان [وحدة التحكم بالذراع ونموذج الجاذبية](../host/arm-control/README.md).

للحصول على آلية جديدة: [معايرة الإزاحات والحدود](settings/README.md#choose-the-reference-pose)، تسجيل الوضعيات، ثم ضبط التعويض والتحقق من صحته. حافظ على المعايرة التي تم التحقق منها عند إعادة استخدام الأوضاع الحالية ونماذج الجاذبية.

| أداة | الغرض |
| --- | --- |
| [الضبط الآلي](tuning/README.md) | قارن مجموعات الإعدادات المحدودة بالتحركات المتكررة وفترات التحقق الأطول. |
| [عارض القياس عن بعد](simulation/README.md) | عرض القياس عن بعد المباشر وتشغيل التسجيلات باستخدام الطرز المجمعة SO-101 وSO-102؛ لا يوجد وصول للحافلة. |
| [العملية عن بعد](teleoperation/README.md) | السيطرة على متابع من hand-operated زعيم. |
| [التسجيل وإعادة التشغيل](poses/README.md) | سجل الوضعيات المسماة؛ أعد التشغيل باستخدام الإعدادات القديمة أو الملحقة، أو قم بتشغيل جلسة تشغيل عن بعد مسجلة. |
| [الاكتشاف والمعايرة والإعدادات](settings/README.md) | ابحث عن المحركات، وقم بمعايرة إزاحات وحدود المفاصل، وقم بعمل نسخة احتياطية من الإعدادات المستمرة أو استعادتها. |
| [اختبارات مقارنة الأجهزة](hw-diff-tests/README.md) | قارن سلوك المصنع والبرامج الثابتة المخصصة على منصة مؤازرة مخصصة. |
| [مقياس ناقل الاتصال والقياس عن بعد](diagnostics/README.md) | قم بقياس زمن الوصول للاتصالات وتحقق من القراءات الثابتة بحثًا عن قيم غير عادية. |
| [تفليش البرامج الثابتة والاسترداد](flash/README.md) | قم بتحديث البرامج الثابتة المخصصة أو المجمعة للمصنع، واستعادة التحميلات المتقطعة وإصلاح إعدادات المصنع. |

تتطلب أدوات Node.js Node.js 20 أو أحدث. يتطلب التفليش واسترداد الإعدادات لغة Python 3.10 أو أحدث. تستخدم المحاكاة لغة بايثون 3.12. قم بتشغيل الأوامر من جذر المستودع واتبع الدليل ذي الصلة قبل توصيل الأجهزة: يمكن أن تؤدي اختبارات المقارنة إلى نقل المحركات واستبدال الإعدادات، ويمكن أن يؤدي التفليش إلى إتلاف أجهزة مؤازرة.

<a id="offline-checks"></a>
## الشيكات دون اتصال

تشغيل من جذر المستودع. قم بتثبيت تبعيات Node ومتطلبات كل أداة من أدوات Python أولاً. لا يفتح أي من هذه الأوامر منفذًا تسلسليًا أو ينقل الأجهزة.

| الأمر | التغطية |
| --- | --- |
| `make verify` | بناء البرامج الثابتة، واختبارات الانحدار C، والعقود register/storage وتخطيط الصورة. راجع [إعداد سلسلة الأدوات](../firmware/README.md). |
| `npm test` | برنامج التشغيل ووحدة التحكم المشتركة وجميع أدوات Node.js. |
| `npm run test:driver-package` | تعبئة برنامج التشغيل والتثبيت المعزول باستخدام تبعيات npm المخزنة مؤقتًا. |
| `make flash-verify PYTHON=tools/flash/.venv/bin/python` | التفليش واستعادة إعدادات المصنع باستخدام الأجهزة التسلسلية المحاكاة. |
| `PYTHONPATH=tools/simulation tools/simulation/.venv/bin/python -m unittest discover -s tools/simulation/test` | النماذج وتسجيل القراء وسلوك المشاهد. |

تستخدم مقارنة الأجهزة [مجموعة المقاعد المخصصة](hw-diff-tests/README.md)؛ يمكنه استبدال الإعدادات وإعادة تعيين القوالب. استخدم [التشخيص](diagnostics/README.md) للاتصالات والقياس عن بعد الثابت على آلية مجمعة.
