# SO-101 النموذج المتبع

تم نسخ الشبكات URDF و13 المشار إليها STL دون تغيير من [مستودع SO-ARM100 الخاص بـ Robot Studio](https://github.com/TheRobotStudio/SO-ARM100/tree/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101)، الالتزام `a758567c3978dfeefe282ede0500085a48fe8f78`.

المصدر: استوديو الروبوت، SO-101. موزعة تحت المنبع [رخصة أباتشي 2.0](../../../../../../../tools/simulation/urdf/so101/LICENSE.txt). `source.json` يسرد المسارات الأولية و SHA-256 المجاميع الاختبارية. يستخدم المشاهد `so101_new_calib.urdf`؛ leader-specific الأجزاء ومتغير المعايرة الأقدم غير مجمعة.

يقوم المستورد بإزالة التصادمات فقط في ملفات المعاينة المؤقتة. فهو يحافظ على الهندسة البصرية، وتحويلات المفاصل وخصائص القصور الذاتي. راجع [دليل العارض](../../README.md) للتعرف على خرائط التشفير وافتراضات المعايرة.
