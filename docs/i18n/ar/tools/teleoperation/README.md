# التشغيل عن بعد

قم بتحريك تابع قوي عن طريق تحريك قائد غير قوي باليد. يدعم 1–6 أزواج المفاصل في حافلتين تسلسليتين منفصلتين. يجوز للقائد استخدام البرامج الثابتة الخاصة بالمصنع؛ يتطلب المتابع البرنامج الثابت v9 لهذا المستودع.

<a id="run"></a>
## تشغيل

قم بتثبيت Node.js 20 أو الأحدث، ثم قم بتشغيل `npm install` من جذر المستودع. انسخ [example.json](../../../../../tools/teleoperation/example.json) بجانب الأصل كـ `controller.local.json`. قم بتعيين المنافذ ومعدل الباود والمعرفات المشتركة. يشارك المثال [ملف تعريف المحرك](../../../../../host/arm-control/profile.example.json) مع إعادة التشغيل والضبط. انسخه لإعداداتك الخاصة وقم بتحديث مساره، أو قم بتضمين ملفات التعريف الخاصة بك. المسارات مرتبطة بملف وحدة التحكم. توضح مكاسب المثال التنسيق؛ استخدم الإعدادات التي تم اختبارها على آليتك.

معاينة التعيين دون تغيير أي إعدادات للمحرك:

```sh
npm run teleoperate -- CONFIG.json
```

تحقق من المواقف والأهداف المبلغ عنها، وادعم كلا الآليتين، واترك مجالًا للتابع للتحرك نحو وضعية القائد. بدء التحكم بشكل صريح:

```sh
npm run teleoperate -- CONFIG.json --run
```

يجب أن يحتوي كل ناقل على المعرفات التي تم تكوينها بالضبط. تحتاج كلتا الآليتين إلى حدود موضعية محفوظة وغير فارغة ووضع موضعي عادي مع دقة الوحدة. يجب أن تكون إعدادات التابع مقفلة مع عدم وجود كتابة مؤجلة معلقة. يجب أن يكون عزم الدوران الرئيسي متوقفًا بالفعل؛ هذه الأداة لا تكتب أبدًا إلى القائد. يتعامل بدء التشغيل التابع مع المحركات التي تعمل بالطاقة وغير المزودة بالطاقة تلقائيًا.

يستمر التشغيل حتى Ctrl+C ما لم تقم بتعيين `durationMs` بشكل صريح. **الخروج العادي يحتفظ بتعليق الطاقة.** يتبع تنظيف بدء التشغيل والجاذبية والفشل [سلوك وحدة التحكم المشتركة](../../host/arm-control/README.md#control-behaviour).

<a id="mapping-and-control"></a>
## رسم الخرائط والتحكم

يحتوي كل إدخال `joints` على `leaderId` و`followerId` و`mapping`:

| الإعداد | معنى |
| --- | --- |
| `mapping: "angle"` | الحفاظ على إزاحة التشفير من مركز الحدود المخزنة. |
| `mapping: "range"` | قم بقياس كل نصف من رحلة القائد إلى النصف التابع المقابل. مفيد للقابضين. |
| `direction` | `1` (افتراضي) أو `-1` لعكس الحركة. |
| `leaderMiddle`, `followerMiddle` | مراكز اختيارية لرسم خرائط النطاق، بدقة داخل الحدود المعنية. |

يتم تقييد الأهداف بالحدود المحفوظة للمتابع. `angle` يعمل بأعداد التشفير، لذا فإنه يفترض مقاييس التشفير والتروس المتوافقة.

مركز التعيين هو نقطة المنتصف للحدود المحفوظة، والتي قد تختلف عن مرجع المعايرة عند 2048. وبالتالي فإن مطابقة المعايرة وحدها لا تضمن مطابقة الأهداف عندما تكون حدود القائد والتابع غير متماثلة. قم بمعاينة الخريطة قبل التحرك. مراكز التجاوز `leaderMiddle` و `followerMiddle` فقط لرسم الخرائط `range`.

توفير ملف تعريف لكل متابع وإعدادات acceleration/ramp المشتركة كما هو موضح في [إعدادات المحرك](../../host/arm-control/README.md#motor-settings-files). أضف `gravityModel` لتمكين [تعويض الجاذبية](../../host/arm-control/README.md#enable-gravity).

<a id="timing-and-checks"></a>
## التوقيت والشيكات

| الإعداد الاختياري | الافتراضي | معنى |
| --- | --- | --- |
| `hz` | 60 | معدل التحديث المطلوب، 1–60 هرتز. يتم تخطي الفترات الضائعة. |
| `maxAgeMs` | 100 | الحد الأقصى لعمر الإطار الرئيسي قبل الإرسال، 10–10000 مللي ثانية. |
| `responseTimeoutMs` | 100 | مهلة الاستجابة وقائمة انتظار المعاملات، 25–10000 مللي ثانية. |
| `durationMs` | غير محدود | مدة التشغيل بما في ذلك بدء تشغيل التحكم، 1–86400000 مللي ثانية. |

يجب أن يتضمن كل إطار كل منصب قيادي ويظل ضمن `maxAgeMs` حتى يتم إرساله. يتم تخطي فترات التحديث المفقودة. تتشارك ردود الفعل والجاذبية والتسجيل في حلقة التحكم؛ تعتمد السرعة المحققة على أداء ناقل الاتصال والكمبيوتر. راجع [الفحوصات المشتركة والتوقيت](../../host/arm-control/README.md#checks-and-timing).

يتم حفظ السجلات في تجاهل `logs/motion/` كـ newline-delimited JSON. أنها تحتوي على التكوين والجلسة المختارة ID والمعاينة والأوامر المقصودة والإطارات المرسلة والتعليقات والسجلات stop/error. لا يثبت سجل الأمر وحده أنه تم إرسال الهدف أو قبوله. يتم انتظار عمليات الكتابة دون تراكم قائمة انتظار سجل غير محدودة؛ قد يؤدي التسجيل البطيء إلى تشغيل الفحص frame-age.

إعادة تشغيل السجلات بدون قائد متصل باستخدام [recorded-session أمر إعادة التشغيل](../poses/README.md#replay-a-recorded-session).

قم بإجراء الاختبارات دون الاتصال بالإنترنت باستخدام `npm run test:teleoperation`.
