<a id="flash-firmware"></a>
# Прошивка

Установите пользовательскую или заводскую прошивку на совместимый **GD32F130 STS TTL сервопривод**. Один загрузчик обрабатывает оба; манифест выпуска выбирает проверки приложения.

**Внимание: перепрошивка прошивки может повредить сервопривод, стереть калибровку или сделать его непригодным для использования. Используйте этот инструмент на свой страх и риск. Восстановление не гарантировано.**

Используйте образ прошивки издателя и соответствующий `release.json`, хранящийся в той же папке. Необработанные сборки прошивки не поддерживаются. Перед прошивкой проверьте аппаратную совместимость версии.

<a id="install"></a>
## Установить

Требуется **Python 3.10 или новее**. Запускаем из корня репозитория:

```sh
python3 -m venv tools/flash/.venv
source tools/flash/.venv/bin/activate
python -m pip install -r tools/flash/requirements.txt
```

В Windows вместо этого активируйте с помощью `tools\flash\.venv\Scripts\Activate.ps1`.

<a id="choose-firmware"></a>
## Выбрать прошивку

| Прошивка | Манифест |
| --- | --- |
| Пользовательское расширение v9 | Загрузите изображение издателя и `release.json` вместе в `tools/flash/releases/`. |
| Завод **SCServo21-GD32-TTL 3.10**, модель **9.3** | В комплекте по адресу [`factory/release.json`](../../../../../tools/flash/factory/release.json), рядом с изображением. |

Заводской образ предназначен только для соответствующего оборудования. Используйте выбранный манифест с `inspect`, `flash` или `recover`; отдельная заводская команда или режим не требуются.

<a id="prepare"></a>
## Подготовьтесь

- Обычное прошивка сбрасывает только выбранный двигатель ID. Двигатели с уникальными идентификаторами могут оставаться подключенными; прошивайте их последовательно, пока остальные работают нормально. Не power-cycle автобус и не запускайте другой загрузчик во время передачи.
- Для **восстановления** подключайте только нужный сервопривод. Восстановление не выбирает двигатель по ID, и передача загрузчика не выполняется.
- Закрепите механизм, используйте стабильную мощность двигателя и закройте другие программы, используя последовательный порт.
- Для нормального прошивки отключите крутящий момент, запишите настройки блокировки и удалите все активные сигналы тревоги с помощью обычного инструмента управления. Узнайте ток сервопривода ID и скорость передачи данных.
- Создайте резервную копию важных калибровок и настроек. Начните с настроек, сохраненных в сервоприводе; временные изменения могут исчезнуть после перезагрузки.

Замените порт и ID своими значениями. Скорость передачи данных по умолчанию — **1,000,000**; добавьте, например, `--baud 500000`, если необходимо. Типичные порты: `/dev/cu.usbmodem…` в macOS, `/dev/ttyUSB0` в Linux и `COM3` в Windows.

```sh
python tools/flash/settings.py backup \
  --port /dev/cu.usbmodemYOUR_ADAPTER --id 2 \
  --file backups/servo-2-settings.json
```

Сохраните эту резервную копию именно для этого сервопривода. Существующие файлы резервных копий не перезаписываются.

<a id="flash"></a>
## Вспышка

Проверьте и прошейте загруженную пользовательскую версию:

```sh
python tools/flash/flash.py inspect \
  --manifest tools/flash/releases/release.json

python tools/flash/flash.py flash \
  --manifest tools/flash/releases/release.json \
  --port /dev/cu.usbmodemYOUR_ADAPTER --id 2
```

Чтобы установить комплектную заводскую прошивку, выберите вместо нее ее манифест. Изолируйте сервопривод для этой операции: заводской запуск может изменить его ID на 1, что будет конфликтовать с другим двигателем на шине.

```sh
python tools/flash/flash.py flash \
  --manifest tools/flash/factory/release.json \
  --port /dev/cu.usbmodemYOUR_ADAPTER --id 2
```

`inspect` проверяет размер файла, контрольную сумму и манифест без подключения к сервоприводу. Введите `FLASH` при появлении запроса. Не отключайте питание до завершения команды. Инструмент проверяет сервопривод, сохраняет снимок его настроек, загружает прошивку, затем проверяет приложение и сравнивает настройки. Успешная проверка оставляет крутящий момент отключенным.

После заводской прошивки инструмент проверяет предыдущие ID/baud, затем ID **1** со скоростью **1,000,000**, если необходимо, и печатает рабочее соединение. Код выхода **2** означает, что заводская прошивка ответила, но настройки изменились. Продолжайте восстанавливать настройки ниже, а не перепрошивать снова.

<a id="recover-an-unresponsive-servo"></a>
## Восстановить не отвечающий сервопривод

Сначала проверьте питание, проводку, ID и скорость передачи данных. Если необходимо восстановление, подключите **только нужный сервопривод** и используйте выбранный манифест. Например, для восстановления заводской прошивкой:

```sh
python tools/flash/flash.py recover \
  --manifest tools/flash/factory/release.json \
  --port /dev/cu.usbmodemYOUR_ADAPTER --id 1
```

После подтверждения **power-cycle сервопривод при появлении запроса**, оставив адаптер USB подключенным. Инструмент ожидает загрузчика до 60 секунд.

Используйте ID и скорость передачи данных, ожидаемую после восстановления. Recovery не может проверить текущую модель или сделать резервную копию настроек перед загрузкой, поэтому убедитесь в совместимости оборудования самостоятельно. Проверьте калибровку и пределы положения, прежде чем в дальнейшем включать крутящий момент.

<a id="restore-factory-settings"></a>
## Восстановить заводские настройки

После возврата к заводской прошивке восстановите резервную копию сервопривода, даже если изначально настройки выглядят правильно. Заводская прошивка может использовать значения по умолчанию built-in, если сохраненные настройки недействительны; обычная запись в регистр может не исправить это.

Используйте **текущий** ID/baud, напечатанный после перепрошивки. Например, если теперь он отвечает как ID 1:

```sh
python tools/flash/settings.py restore \
  --port /dev/cu.usbmodemYOUR_ADAPTER --id 1 \
  --file backups/servo-2-settings.json
```

Введите `RESTORE` для подтверждения. Это поддерживает заводскую **3.10** и отклоняет обнаруженную пользовательскую прошивку. Он восстанавливает настройки, **заменяет сохраненный шаблон сброса**, восстанавливает сохраненные настройки, блокирует запись и перезапускает сервопривод. Он следует за любыми изменениями ID/baud и проверяет обратное чтение без отправки команд движения.

Затем **power-cycle сервопривод** и проверьте, используя **восстановленный** ID/baud:

```sh
python tools/flash/settings.py verify \
  --port /dev/cu.usbmodemYOUR_ADAPTER --id 2 \
  --file backups/servo-2-settings.json
```

Не закручивайте крутящий момент до тех пор, пока проверка не пройдет. Вы также можете указать обычную вспышку `report.json`, содержащую снимок before-flash, как `--file`. Резервные копии, сделанные после потери настроек, не могут восстановить исходную калибровку. Без действительной резервной копии получите настройки для точной модели и повторно откалибруйте этот сервопривод.

В случае сбоя восстановление пытается повторно заблокировать настройки, но не отменяет частичную запись и не повторяет автоматическое восстановление. Сохраните отчет перед расследованием.

<a id="results-and-options"></a>
## Результаты и варианты

Flash-отчеты сохраняются под `backups/flash/`; отчеты о настройках в разделе `backups/settings/`. Оба включают доступные снимки настроек. Успешная загрузка включает в себя проверку приложения; он не считывает полный образ прошивки. Настройки не восстанавливаются автоматически.

- `--output DIRECTORY`: выберите место сохранения отчетов.
- `--yes`: пропустить запрос подтверждения; все проверки продолжают выполняться.
- `--help`: показать параметры команды.

Если проверка файла не удалась, получите соответствующую пару выпусков. Если прошивка прервано, возможно, сервоприводу потребуется восстановление. Если передача завершена, но проверка не удалась, просмотрите отчет и проверьте ID, скорость передачи данных и настройки перед повторной попыткой.

Для авторов выпусков: [release.example.json](../../../../../tools/flash/release.example.json) показывает пользовательский манифест, а [factory/release.json](../../../../../tools/flash/factory/release.json) — заводской манифест. Пользовательский пример не является пригодной для использования версией прошивки.
