# Иллюстрации калибровки

Виды сбоку и сверху, полученные из комплектных моделей роботов, с добавленными метками соединений и инструкциями по размещению. Это руководства по **новой ручной калибровке**, а не фотографии или измерения настроенных рычагов.

- `so101-reference-pose.png`: геометрия SO-101 из Robot Studio, распространяемая под Apache-2.0. [Прикрепленный исходный код и лицензия](../../simulation/urdf/so101/README.md).
- `so102-reference-pose.png`: геометрия SO-ARM-102 Робонина, CC BY 4.0. [Прикрепленный исходный код и лицензия](../../simulation/urdf/README.md). Эта иллюстрация представляет собой адаптацию позы, камеры, фона и меток, установленных для этого руководства; он также доступен под номерами CC BY 4.0.

<a id="poses-used-in-the-images"></a>
## Позы, использованные в изображениях

M1–M4 используют связанные сопоставления средств просмотра на счете 2048. Положения поворота запястья и захвата устанавливаются отдельно по средним точкам пределов перемещения модели. Физические упоры реального механизма определяют эти средние точки во время ручного размещения.

| Модель | M1–M4 углы суставов | Запястье рулон | захват |
| --- | --- | --- | --- |
| SO-101 | 0°, 0°, 0°, 0° | 2.789° | Подвижная челюсть 45° |
| SO-102 | 0°, −3°, 1°, 1° | −1° | Позиции скользящей челюсти +0.02075 м и −0.02075 м |

Углы указаны относительно каждой шарнирной рамы URDF, а не углов, измеренных относительно стола. Эти позиции wrist/gripper отличаются от карт просмотра по умолчанию; ни карты, ни опубликованные гравитационные модели для этих изображений не были изменены. Чтобы соответствовать новой калибровке, обновите опорные углы средства просмотра и привязку калибровки, как описано в [руководстве по просмотру](../../simulation/README.md#match-the-calibration-reference).
