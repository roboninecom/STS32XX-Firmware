<a id="discovery-calibration-and-settings"></a>
# Обнаружение, калибровка и настройки

Найдите STS сервоприводы и создайте резервную копию или восстановите их постоянные Legacy настройки. Использует общий драйвер репозитория и управляющую таблицу STS. Требуется Node.js 20 или новее. Запустите эти команды из корня репозитория после `npm ci`.

<a id="discover"></a>
## Откройте для себя

```sh
npm run settings -- discover --port /dev/cu.usbmodemYOUR_ADAPTER
```

Отображает идентификаторы отвечающих двигателей и сообщаемые сигналы тревоги как JSON. Обнаружение составляет read-only и сканирует выбранную скорость передачи данных, которая по умолчанию равна 1,000,000. Добавьте `--baud 500000` для другой поддерживаемой скорости. В Linux или Windows используйте порт адаптера, например `/dev/ttyUSB0` или `COM3`.

Двигатели должны иметь уникальные идентификаторы. Discovery не может надежно распознать двигатели, имеющие общий номер ID, или найти двигатели, использующие другую скорость передачи данных.

<a id="back-up"></a>
## Резервное копирование

```sh
npm run settings -- backup --port /dev/cu.usbmodemYOUR_ADAPTER --id 2 \
  --file tools/settings/backups/servo-2.json
```

Сохраняет идентификационные данные устройства и все постоянные настройки, описанные в общей таблице управления, включая калибровку, пределы, усиление, ID и переключатель скорости. Бэкап читает только мотор. Существующие файлы никогда не перезаписываются. Без `--file` файл с отметкой времени создается под `tools/settings/backups/`, который игнорируется Git.

<a id="restore"></a>
## Восстановить

Подключайте только восстанавливаемый двигатель, отключайте крутящий момент, блокируйте настройки и сбрасывайте активные сигналы тревоги. Закройте другие программы, использующие порт. Используйте резервную копию того же двигателя: восстановление калибровки другого двигателя может изменить его сообщаемое положение.

```sh
npm run settings -- restore --port /dev/cu.usbmodemYOUR_ADAPTER --id 2 \
  --file tools/settings/backups/servo-2.json
```

`--id` и `--baud` описывают **текущее соединение**. Резервная копия может восстановить другую ID или скорость передачи данных; инструмент следует за этими изменениями и сообщает об окончательном соединении. Он проверяет идентичность модели, записывает только измененные настройки, ждет завершения каждого сохраненного диапазона регистров, считывает настройки обратно и повторно блокирует двигатель. Он никогда не включает крутящий момент и не отправляет команду движения. Неудачное восстановление может привести к изменению некоторых настроек; проверьте ошибку перед повторной попыткой.

Эти резервные копии охватывают Legacy настройки, а не конфигурацию расширений или шаблон сброса настроек к заводским настройкам. Для восстановления после прошивки заводской прошивки поверх пользовательской прошивки используйте [инструмент восстановления заводских настроек](../flash/README.md#restore-factory-settings). Его файлы резервных копий используют другой формат и не являются взаимозаменяемыми с файлами JSON этого инструмента.

<a id="calibrate-joint-offsets-and-limits"></a>
## Калибровка смещений и пределов соединений

Калибровка двигателей 1–6 с уникальными идентификаторами от 1 до 253 и механически ограниченным ходом шарнира. Поддерживает семейство моделей GD32 STS 9, включая варианты смешанных двигателей, в режиме положения с делителем положения 1. Закройте другие последовательные инструменты.

```sh
npm run settings -- calibrate --port /dev/cu.usbmodemYOUR_ADAPTER --ids 1,2,3 \
  --file tools/settings/calibrations/arm.json
```

Замените идентификаторы примеров на свои двигатели. Опустите `--ids`, чтобы откалибровать все обнаруженные двигатели, до шести. Явный выбор оставляет без изменений другие подключенные двигатели. Никакие названия суставов, геометрия рук или стандартная исходная поза не предполагаются.

<a id="choose-the-reference-pose"></a>
### Выберите эталонную позу

**Эталонная поза для калибровки** — это физическая поза, которую вы запечатлели на шаге 1. Инструмент выдает отчет о каждом выбранном двигателе **2048 в этой позе**. Он не распознает позу, не определяет углы суставов и не рассчитывает их на основе более позднего сканирования.

Для новой калибровки поместите каждое соединение примерно в середину его механического перемещения и выберите положение, которое вы можете воспроизвести. Включите валик для запястья и захват; не думайте, что захват должен быть полностью открыт или закрыт. Каждый раз используйте одну и ту же физическую позу. Если у механизма есть документированная эталонная поза, следуйте ей. Для SO-101 [руководство по калибровке LeRobot и видео ](https://huggingface.co/docs/lerobot/so101#calibrate) показывают размещение mid-travel с последующим движением end-to-end.

### Эталонные изображения поз

Для **новой калибровки** используйте приведенные ниже инструкции. На этикетках указаны обычные идентификаторы двигателей 1–6. Поместите основание вертикально, плечо вертикально, а предплечье и захват должны быть направлены вперед, как показано на рисунке. Отцентрируйте вращение основания и вращение запястья между механическими упорами; установите захват на полпути между закрытым и открытым положением. Используйте физическое путешествие, чтобы найти эти позиции, а не некалиброванные отсчеты.

Шарнир с почти полным ходом требует особенно тщательного центрирования. Повторяемая поза возле конечной остановки может не оставить достаточно места, даже если общий ход меньше поворота.

<a id="capture-offsets-then-limits"></a>
### Захват смещений, а затем ограничений

Оба шага выполняются одной командой:

1. **Опорная поза**. Поместите выбранные соединения в повторяемую позу, выбранную для вашего механизма. Поддержите его, задержитесь и нажмите **Enter**. Инструмент записывает смещения двигателя, поэтому каждое выбранное соединение считывает **2048** в захваченной позе, а затем проверяет сохраненные регистры.
2. **Ограничения суставов**: перемещайте каждый выбранный сустав из конца в конец. Сделайте короткую паузу на каждом конце; не останавливайтесь принудительно. Просмотрите текущие значения минимума, максимума, средней точки и хода, затем нажмите **Ввод**. Инструмент записывает пределы с **10 отсчетами зазора** внутри каждой измеренной конечной точки.

**Средний** таблицы равен `(Min + Max) / 2`, округленному до целого числа. Это носит информационный характер: сохранение пределов не перемещает 2048 к этой средней точке и не меняет смещения. Асимметричные пределы действительны.

Если при запуске на двигатели подается питание, инструмент попросит вас поддержать механизм, прежде чем ослаблять крутящий момент. В противном случае есть только два приглашения выше. Никакого движения не требуется; крутящий момент остается выключенным, а настройки блокируются после сохранения.

При захвате эталона используется медиана нескольких показаний. Небольшие движения руки не останавливают калибровку, а небольшое перемещение во время сохранения смещений не требует дополнительного подтверждения. Неудачные сохранения настроек остаются рядом с затронутым двигателем и повторяются автоматически. Инструмент считывает данные перед повторной попыткой записи, поэтому отсутствие подтверждения не приводит к повторной записи настроек already-saved. Готовые двигатели сохраняются; никаких дополнительных подтверждений не требуется.

Смещения сохраняются перед разверткой и не изменяются при сохранении пределов. Пределы могут быть асимметричными в районе 2048. Отслеживается циклическое завершение кодирования; пересечение диапазона 0 или 4095 не может быть сохранено как обычные пределы и отображается `crosses zero` в столбце **Проверить**. Каждый сустав должен двигаться как минимум на 64 счета и менее чем на полный оборот, прежде чем его пределы можно будет сохранить.

Временные ошибки чтения появляются рядом с затронутым двигателем и автоматически исчезают, когда возобновляются действительные показания. Более быстрое движение руки не вызывает ошибку speed-limit. Ввод сохраняет только тогда, когда все диапазоны действительны; в противном случае запись продолжается с сохранением измерений. Используйте `reset 2`, чтобы очистить только измеренный диапазон M2 и снова просканировать это соединение, не повторяя эталонный шаг или другие соединения. Настоящий диапазон, пересекающий ноль, по-прежнему нуждается в корректировке опорного положения; сброс измерений не может обеспечить соответствие этому физическому диапазону. Все ошибки двигателя остаются видимыми рядом с затронутым двигателем. Аварийные сигналы или неожиданная пауза крутящего момента, его настройки записываются до тех пор, пока не будут очищены; потерянные соединения повторяются. Сессия остается открытой и сохраняет выполненную работу. Во время автоматических повторных попыток нажмите Ctrl+C для отмены.

Выходной файл перезаписывается при каждом запуске. Резервные копии двигателя хранятся в уникальном каталоге под `backups/` рядом с этим файлом и могут использоваться с `settings restore`. В отчете фиксируются эталонные показания, смещения, измеренные диапазоны и завершенные записи; он не хранит фотографии или физические углы суставов. Только `status: "verified"` означает, что оба шага выполнены.

Введите `cancel` или нажмите Ctrl+C, чтобы остановить. **Смещения, уже сохраненные на этапе 1, остаются сохраненными, если шаг 2 отменен или не выполнен; старые пределы остаются до тех пор, пока не будут заменены.** Завершите калибровку перед включением движения. Вы можете повторно запустить ту же команду из исходной позы, не восстанавливая предыдущую калибровку JSON.

<a id="expected-travel-warnings"></a>
### Ожидаемые предупреждения о поездках

Опционально можно передать `--expected-ranges FILE.json`, содержащий проверенные значения хода и допуски, кодируемые двигателем ID. Пример формата:

```json
{"1": {"counts": 2000, "tolerance": 100}}
```

Эти цифры только иллюстрируют формат файла. Отклонения отображаются в виде предупреждений; нажатие Enter принимает измеренный диапазон. Пропущенные соединения не имеют проверки expected-range.

Завершите калибровку перед записью поз или установкой компенсации гравитации. После изменения смещений снова запишите позы и обновите или измените гравитационную модель и отображение симулятора. Ни один из них не обновляется этой командой. Копирование смещений другой руки или изменение только полей модели calibration-check не устанавливает правильную взаимосвязь между счетчиками и углами.

<a id="help-and-tests"></a>
## Помощь и тесты

```sh
npm run settings -- --help
npm run test:settings
```

Тесты выполняются в автономном режиме без открытия последовательного порта. В случае сбоя команды завершаются с ненулевым статусом; пустой список обнаружения означает отсутствие ответов на выбранной скорости.
