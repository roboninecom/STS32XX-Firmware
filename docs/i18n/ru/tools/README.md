<a id="tools"></a>
# Инструменты

Утилиты для работы с сервомашинками STS. Каждое руководство включает инструкции по настройке, команды и требования к оборудованию. Для разработки приложений используйте [серводрайвер Node.js](../host/servo-driver/README.md), доступный как отдельный пакет npm, созданный из этого репозитория. Воспроизведение и телеоперация используют [контроллер руки и модель гравитации](../host/arm-control/README.md).

Для нового механизма: [калибровка смещений и пределов](settings/README.md#choose-the-reference-pose), запись поз, затем настройка и проверка компенсации. Сохраняйте проверенную калибровку при повторном использовании существующих поз и моделей гравитации.

| Инструмент | Цель |
| --- | --- |
| [Автоматическая настройка](tuning/README.md) | Сравните ограниченные пакеты настроек с повторяющимися перемещениями и более длительными проверками. |
| [Просмотр телеметрии](simulation/README.md) | Просматривайте телеметрию в реальном времени и воспроизводите записи с помощью встроенных моделей SO-101 и SO-102; нет доступа к автобусу. |
| [Телеоперация](teleoperation/README.md) | Управляйте последователем лидера hand-operated. |
| [Запись и воспроизведение](poses/README.md) | Запишите названные позы; воспроизведите повтор с Legacy настройками или настройками расширения или воспроизведите записанный сеанс телеоперации. |
| [Обнаружение, калибровка и настройки](settings/README.md) | Найдите двигатели, откалибруйте смещения и ограничения соединений, а также создайте резервные копии или восстановите постоянные настройки. |
| [Сравнительные тесты оборудования](hw-diff-tests/README.md) | Сравните поведение заводской и пользовательской прошивки на специальном стенде для сервоприводов. |
| [Бенчмарк шины и телеметрия](diagnostics/README.md) | Измерьте задержку связи и проверьте стационарные показания на наличие необычных значений. |
| [Прошивка и восстановление прошивки](flash/README.md) | Установите пользовательскую или встроенную заводскую прошивку, восстановите прерванную загрузку и восстановите заводские настройки. |

Для инструментов Node.js требуется Node.js 20 или новее. Для прошивки и восстановления настроек требуется Python 3.10 или новее. В моделировании используется Python 3.12. Запускайте команды из корня репозитория и следуйте соответствующему руководству перед подключением оборудования: сравнительные тесты могут сдвинуть двигатели и перезаписать настройки, а перепрошивка может повредить сервопривод.

<a id="offline-checks"></a>
## Оффлайн проверки

Запуск из корня репозитория. Сначала установите зависимости Node и требования каждого инструмента Python. Ни одна из этих команд не открывает последовательный порт и не перемещает оборудование.

| Команда | Покрытие |
| --- | --- |
| `make verify` | Сборка прошивки, регрессионные тесты C, контракты register/storage и макет образа. См. [Настройка набора инструментов](../firmware/README.md). |
| `npm test` | Драйвер, общий контроллер и все инструменты Node.js. |
| `npm run test:driver-package` | Упаковка драйверов и изолированная установка с использованием кэшированных зависимостей npm. |
| `make flash-verify PYTHON=tools/flash/.venv/bin/python` | Перепрошивка и восстановление заводских настроек с помощью симулированных последовательных устройств. |
| `PYTHONPATH=tools/simulation tools/simulation/.venv/bin/python -m unittest discover -s tools/simulation/test` | Модели, записывающие читателей и поведение зрителей. |

Для сравнения оборудования используется [специальный стендовый пакет](hw-diff-tests/README.md); он может заменять настройки и сбрасывать шаблоны. Используйте [диагностику](diagnostics/README.md) для связи и стационарной телеметрии на собранном механизме.
