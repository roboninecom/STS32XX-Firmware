# SO-101 модель последователя

URDF и 13 ссылаются на сетки STL, скопированные без изменений из [репозитория SO-ARM100 The Robot Studio](https://github.com/TheRobotStudio/SO-ARM100/tree/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101), коммит `a758567c3978dfeefe282ede0500085a48fe8f78`.

Источник: The Robot Studio, SO-101. Распространяется по исходной [лицензии Apache 2.0](../../../../../../../tools/simulation/urdf/so101/LICENSE.txt). `source.json` перечисляет восходящие пути и SHA-256 контрольные суммы. Зритель использует `so101_new_calib.urdf`; Детали leader-specific и более старый вариант калибровки не входят в комплект.

Импортер удаляет коллизии только во временных файлах предварительного просмотра. Он сохраняет визуальную геометрию, суставные преобразования и инерционные свойства. См. [руководство по просмотру](../../README.md), где приведены предположения о сопоставлении энкодера и калибровке.
