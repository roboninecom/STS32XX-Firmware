<a id="telemetry-viewer"></a>
# Просмотрщик телеметрии

Просматривайте телеметрию в реальном времени или воспроизводите запись контроллера в MuJoCo. Средство просмотра читает файлы журналов; он никогда не подключается к двигателям и не отправляет команды. Обе модели используют одно и то же средство просмотра, диаграммы и наложение ссылок. Он отображает записанное движение; он не прогнозирует динамику двигателя или результаты настройки.

<a id="install"></a>
## Установить

Из корня репозитория, используя Python 3.12:

```sh
python3.12 -m venv tools/simulation/.venv
tools/simulation/.venv/bin/python -m pip install -r tools/simulation/requirements.txt
```

<a id="live-and-recorded-playback"></a>
## Живое и записанное воспроизведение

Запустите один раз, чтобы просмотреть новейший сеанс и автоматически переключиться, когда другой повтор или запуск телеоперации создаст журнал:

```sh
mkdir -p logs/motion
tools/simulation/.venv/bin/python tools/simulation/viewer.py live logs/motion --model so101
```

Каталог должен существовать. Пустой каталог ожидает своего первого журнала. Настройки окна, камеры и дисплея остаются неизменными между запусками; графики сбрасываются для каждой новой сессии. Запустите аппаратное воспроизведение отдельно в другом терминале.

Чтобы следить за одним конкретным журналом или воспроизвести сохраненный журнал с самого начала:

```sh
tools/simulation/.venv/bin/python tools/simulation/viewer.py live /path/to/events.ndjson --model so101

tools/simulation/.venv/bin/python tools/simulation/viewer.py play /path/to/events.ndjson --model so101
```

Команда автоматически выбирает встроенную программу запуска окон в macOS, включая пути к репозиторию, содержащие пробелы. Выберите `--model so102` для SO-102; это также значение по умолчанию, если оно опущено. Модели и сетки объединены в пакет, поэтому для просмотра не требуется загрузка или импорт.

Для предварительного просмотра PNG используйте обычный Python на всех платформах:

```sh
tools/simulation/.venv/bin/python tools/simulation/viewer.py play /path/to/events.ndjson --model so101 --render preview.png
```

Средство просмотра принимает журналы событий контроллера, а не файлы с именами JSON. Отправьте файлы поз через [аппаратное воспроизведение](../poses/README.md#replay-poses), затем просмотрите полученный журнал. При воспроизведении сохраняется время записи и сохраняется последний кадр. Дисплей в реальном времени обновляется только после полного прохождения обратной связи двигателя. Задержанные измерения помечаются как устаревшие; команды сами по себе не могут их обновить. Замененный или усеченный журнал необходимо открыть заново. Закрытие средства просмотра оставляет управление оборудованием включенным.

<a id="models-and-calibration"></a>
## Модели и калибровка

| Модель | Источник | Отображение отображения |
| --- | --- | --- |
| `so101` | [Официальный подписчик SO-101](urdf/so101/README.md), Apache 2.0 | Все шесть двигателей, включая поворотное устройство и вращающийся захват. |
| `so102` | [SO-ARM-102](urdf/README.md), CC BY 4.0 | Существующее калиброванное отображение M1–M4; запястья перекатываются, а челюсти остаются неподвижными. |

SO-101 использует восходящий `so101_new_calib.urdf`. Его карта по умолчанию предполагает стандартную сборку и нулевой уровень каждого соединения URDF при счетчике энкодера 2048. Положительные значения увеличивают каждый угол сустава URDF на 2π/4096 радиан на счет. Это соглашение должно соответствовать исходному положению вашей руки и направлению суставов; на дисплее это отображается как **принятая эталонная поза**, а не выравнивание hardware-verified. Захват напрямую использует угол энкодера, а не нормализованное отверстие LeRobot 0–100. Его ноль URDF должен соответствовать углу челюсти по вашей калибровочной ссылке; это не выводится из сохраненных ограничений на поездки.

SO-102 сохраняет существующие зубцы encoder-calibration и фиксированную кулачковую муфту. Изменение модели не меняет аппаратный контроллер или его гравитационную модель.

<a id="match-the-calibration-reference"></a>
### Соответствуйте эталону калибровки

[Инструмент калибровки](../settings/README.md#choose-the-reference-pose) устанавливает 2048 в снимаемой вами позе. Средство просмотра отдельно преобразует эти значения в углы:

```text
angle = referenceRadians + (counts − referenceCount) × radiansPerCount
```

| Карта в комплекте | Отображаются углы суставов, когда счет равен 2048 |
| --- | --- |
| SO-101 | 0° для всех шести URDF суставов; это предположение, а не обнаруженная физическая поза. |
| SO-102 | M1 0°, M2 −3°, M3 1°, M4 1°; M5 и челюсти используют фиксированные позиции отображения. |

Калибровочная поза mid-travel, в том числе показанная в руководстве LeRobot, сама по себе не означает, что каждый угол URDF равен нулю. По полученной ссылке установите `referenceRadians` каждой записи карты на угол этого сустава в URDF. Проверьте легким движением руки, чтобы подтвердить знак `radiansPerCount`, включая перекат запястья и захват. Проверьте также вторую позу; соответствие одной позе не может подтвердить направление или масштаб. Инструмент не вычисляет эти углы на основе минимального и максимального значений.

Карта по умолчанию SO-101 не имеет точной привязки смещения. Карта SO-102 привязана к сохраненным смещениям исходной руки. После повторной калибровки обновите карту физического угла, а также поля калибровки; изменение только этих полей позволяет обойти проверку без исправления отображения. Отчеты о калибровке не импортируются автоматически. Голубое наложение показывает запланированную прошивкой позу или пункт назначения с компактной обратной связью; это отдельно от позы калибровки.

Чтобы настроить или привязать карту к определенной руке, скопируйте `so101-encoder-map.json` или `encoder-angle-map.json`, отредактируйте ее и передайте `--mapping YOUR_MAP.json` с помощью любой команды. Карты версии 2 содержат:

- `model`: должен соответствовать выбранной модели.
- `joints`: идентификаторы двигателей сопоставлены с именами суставов URDF, `referenceCount`, `referenceRadians` и подписаны `radiansPerCount`.
- `fixedJoints`: положения соединений модели без измеренного сопоставления, в радианах для вращающихся соединений или метрах для скользящих соединений.
- `encoderCalibration`: дополнительные точные настройки per-motor, `positionCorrection`, `resolution` и `reverse`, сверяющиеся с записью перед полетом.

Каждое соединение модели должно быть отображено или явно исправлено. Отсчеты в журнале уже включают коррекцию положения сервопривода; не вычитайте его снова. Требуется разрешение энкодера единицы измерения. Реверсивный энкодер требует явной записи калибровки и соответствующего сопоставления угла со знаком. Для пользовательских карт, созданных в предыдущем формате, скопируйте карту версии 2 и перенесите исходные углы и направления.

<a id="display"></a>
## Дисплей

Обе модели имеют нейтральный фон и полупрозрачную сетку в основании. Сетка представляет собой визуальную ссылку без реакции на столкновение; позы под ним остаются видимыми. Воспроизведение сохраняет последний кадр, не зацикливается и не перезапускается. Режим реального времени с файлом следует только за этим файлом. При использовании каталога он следует за новыми файлами `.ndjson` в этом каталоге без поиска подкаталогов или переключения назад при обновлении более старого журнала.

`1`–`6` выберите двигатель; `G` включает наложение ссылки; `C` графики; `J` маркеры суставов; `M`/`R` measured/reference поза; `F` качество рендеринга; `H` помощь. Выбранное соединение имеет метку ошибки. Отсутствующие показания отображаются `--`.

Компактная обратная связь C1 имеет измеренные положения, но не имеет привязки к планировщику; его сравнение использует заданный пункт назначения. Подробная C2 обратная связь предоставляет справочную информацию по планировщику. Ошибка пункта назначения во время движения не является ошибкой отслеживания. В новых журналах повторов используется подробная обратная связь: голубая тень следует за промежуточными запланированными позициями прошивки. В старых журналах compact-feedback все еще отображаются переходы между пунктами назначения; средство просмотра не может восстановить недостающие промежуточные ссылки. Диаграммы сохраняются до 20 секунд и не создают новых временных меток измерений.

Средство просмотра воспроизводит геометрию с отключенными контактами и гравитацией. Он не моделирует динамику двигателя и не прогнозирует настройку PID. Положения соединений отображаются без привязки к номинальным пределам CAD.
