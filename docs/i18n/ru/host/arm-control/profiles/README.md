# Профили рычагов

Эталонные настройки в вертикальном положении, руки empty-gripper. Каждый каталог содержит файл контроллера и один профиль для каждого двигателя, включая PID и прямую связь по скорости. Оба контроллера используют гравитационные модели двигателей 2–4; двигатели 1, 5 и 6 испытывают усилие невесомости.

| Профиль | Скорость воспроизведения | Ускорение | Область применения |
| --- | ---: | ---: | --- |
| [SO-101](../../../../../../host/arm-control/profiles/so101/controller.json) | 1,000 counts/s; профильный потолок 1,500 | 10,000 counts/с² | Сохранены настройки тюнинга. Колебания движения M1 и более медленные экскурсии M2 остаются нерешенными. |
| [SO-102](../../../../../../host/arm-control/profiles/so102/controller.json) | 2,000 counts/s | 15,000 counts/с² | Текущие настройки сравнения fixed-profile. Эта быстрая конфигурация все еще требует аппаратной проверки. |

Это отправные точки, а не универсальные настройки по умолчанию или заявление о завершенной настройке. В профиле SO-102 используются фиксированные M1 D=0.0625, M6 P=4 и линейное изменение 100 мс. В более старом воспроизведении использовалось M1 D=0.75 во время движения, M6 P=16 и линейное изменение 180 мс, поэтому этот файл не воспроизводит тот старый прогон.

<a id="use"></a>
## Использование

Установите `followerPort` в выбранном файле контроллера. Сохраняйте относительный профиль и траектории гравитации нетронутыми. Из корня репозитория:

```sh
npm run replay -- host/arm-control/profiles/so102/controller.json POSES.json
npm run replay -- host/arm-control/profiles/so102/controller.json POSES.json --run
```

Используйте `so101` для другого профиля. Первая команда предварительного просмотра; второй перемещает руку и оставляет ее в конечной позе. Replay применяет профили к RAM. Для дистанционного управления также установите `leaderPort` и добавьте `leaderId`, `mapping` и любые переопределения direction/center к каждому суставу; см. [руководство по сопоставлению](../../../tools/teleoperation/README.md#mapping-and-control).

Гравитационные модели включают калибровку энкодера, использованную во время установки. Предполетная подготовка требует, чтобы он соответствовал подключенному рычагу. **Не копируйте смещения энкодера другого рычага, чтобы выполнить эту проверку.** Откалибруйте рычаг, установите или адаптируйте его модель и проверьте результат на умеренной скорости перед использованием full-speed. Изменения в монтаже, геометрии звеньев или полезной нагрузке также требуют проверки. См. [формат гравитационной модели](../models/README.md) и [процедуру настройки](../../../tools/tuning/README.md).

Эти файлы не определяют универсальную позу физической калибровки. Следуйте инструкциям [reference-pose](../../../tools/settings/README.md#choose-the-reference-pose) перед созданием новой калибровки. Установка всех двигателей на 2048 воспроизводит позу, зафиксированную на этой руке, с учетом сохраненных ограничений и ошибки отслеживания; он не воспроизводит автоматически нулевую позу ни одной из связанных моделей.
