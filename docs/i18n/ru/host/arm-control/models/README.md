# Гравитационные модели

В комплект входят две вертикальные модели empty-gripper:

- `arm-upright-empty.json`: SO-102.
- `so101-upright-empty.json`: SO-101.

Оба включают калибровку энкодера и связанные параметры для двигателей 2–4. Двигатели 1, 5 и 6 имеют явную нулевую компенсацию. Они предполагают оригинальный монтаж, смещения энкодера и геометрию звеньев. Перепроверьте оборудование, прежде чем использовать другую настройку. Соответствующие [профили контроллера](../profiles/README.md) описывают их рабочие настройки и оставшиеся ограничения.

Файл содержит коэффициенты усилия со знаком PWM и настройки кодировщика, с которыми они были сопоставлены. `encoderCalibration` перечисляет поправки положения со знаком, разрешение единицы измерения и реверс энкодера для каждого двигателя. Предполетная подготовка требует, чтобы они соответствовали подключенному рычагу. Лимиты и прибыль — это отдельные настройки.

Калибровка приводит к тому, что захваченная физическая поза отображается как 2048; он не определяет углы соединения, используемые в этих моделях. Эти углы уже включены в термины «веса» и «смещения». Воспроизведение той же позы на другой руке может привести к различным сбоям моторики. Подгоните или адаптируйте модель к этому рычагу и проверьте ее выходные данные; не копируйте смещения из поставляемой модели в двигатели. Изменение только `encoderCalibration` не обновляет расчет силы тяжести. См. [выбор эталонной позы](../../../tools/settings/README.md#choose-the-reference-pose).

У каждого двигателя есть `maxEffort`, поясняющий `note` и список `terms`. Термин вносит `coefficient * sin(angle)` или `coefficient * cos(angle)`, где `angle = offsetRad + sum(measuredEncoderCounts[id] * weights[id])`. Углы – это радианы. Член `constant` дает свой коэффициент и не имеет весов. Пустой список явно требует нулевой компенсации.

Все взвешенные идентификаторы двигателей должны находиться среди управляемых ведомых. Каждому последователю требуется явная модель. При оценке отклоняются отсутствующие входные данные, неопределенные значения и усилия, превышающие либо ограничение модели, либо настроенное ограничение усилия двигателя; он никогда молча не отсекает чрезмерный результат.
