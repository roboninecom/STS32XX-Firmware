# SO-101 modèle suiveur

Les maillages URDF et 13 référencés STL ont été copiés inchangés à partir du [référentiel SO-ARM100 de The Robot Studio](https://github.com/TheRobotStudio/SO-ARM100/tree/a758567c3978dfeefe282ede0500085a48fe8f78/Simulation/SO101), commit `a758567c3978dfeefe282ede0500085a48fe8f78`.

Source : Le Robot Studio, SO-101. Distribué sous la licence [Apache 2.0 amont](../../../../../../../tools/simulation/urdf/so101/LICENSE.txt). `source.json` répertorie les chemins en amont et SHA-256 les sommes de contrôle. Le spectateur utilise `so101_new_calib.urdf` ; Les pièces leader-specific et l'ancienne variante d'étalonnage ne sont pas regroupées.

L'importateur supprime les collisions uniquement dans les fichiers d'aperçu temporaires. Il préserve la géométrie visuelle, les transformations conjointes et les propriétés inertielles. Consultez le [guide de visualisation](../../README.md) pour connaître les hypothèses de mappage et d'étalonnage des encodeurs.
